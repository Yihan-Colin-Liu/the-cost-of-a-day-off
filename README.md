# The Cost of a Day Off

A short, original interactive story about low-income hourly work, access to medical care, and paid sick leave.

## Concept

The player follows Elena Morales, a fictional 31-year-old hotel housekeeping worker who has a clinic appointment for persistent wrist pain.

The story is played twice:

1. **Without paid sick leave**
2. **With paid sick leave**

The health problem, worker, appointment, and everyday pressures remain the same. The key working condition changes. The player can compare how that change affects choices and costs.

The project was designed in relation to:

- Marmot (2006), social determinants of health
- Farmer (2003, pp. 29–50), structural violence
- DeRigne, Stoddard-Dare, and Quinn (2016), paid sick leave and delayed/forgone medical care

## Run locally

No build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

For the cleanest local development experience, you can also use VS Code's Live Server extension.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub will provide a public Pages URL.

## Original assets

The illustrations in `assets/` are original SVG drawings created specifically for this project. They are not copied from a film, game, stock illustration, or other copyrighted artwork.

## Content note

The story is fictional. The character, dialogue, events, and monetary amounts are invented for the project. The research references inform the scenario but do not establish that the fictional events happened to a real person.
